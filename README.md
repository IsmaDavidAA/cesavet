# CESAVET Veterinaria y Emergencias

Sitio de la clínica veterinaria de Cochabamba, en la calle 16 de Julio, entre Calama y Ladislao Cabrera.

Cada push a `main` publica el sitio en GitHub Pages:

https://ismadavidaa.github.io/cesavet/

## Qué editar

- Textos, teléfonos y servicios: `index.html`
- El formulario distingue consulta y urgencia: `script.js`
- Colores y diseño: `styles.css`
